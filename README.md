## 📋 Sobre o Projeto

 **Saúde+** é uma interface web que simula o sistema de um plano de saúde com foco em usabilidade e segurança.

Desenvolvido com **HTML**, **CSS**, **Bootstrap** e **JavaScript**, o projeto entrega uma experiência moderna, responsiva e amigável.

O grande diferencial? Validações robustas em formulários, garantindo que CPF, CNPJ e idade (maior de 18 anos) sejam preenchidos corretamente antes do envio.

---

## 🛠 Tecnologias Utilizadas

-  **HTML5** 
-  **CSS3** 
-  **Bootstrap**   
-  **JavaScript** 

---

## 🎯 Funcionalidades Principais

- ✅ Validação de **CPF** e **CNPJ** com mensagens de erro claras  
- 🔞 Checagem da **idade mínima** (18 anos) para cadastro  
- 📱 Interface **responsiva**, que se adapta a todos os dispositivos  
- 🎨 Design moderno, clean e fácil de navegar  
- ⚡ Feedback instantâneo durante o preenchimento do formulário
